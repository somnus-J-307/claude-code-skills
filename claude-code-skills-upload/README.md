# Claude Code Skills

个人自用的 Claude Code 单文件 Skill 合集。纯 prompt 驱动，零外部依赖，安装即用。

---

## Skills 目录

### 1. diary — 日记引导

当你想写日记但脑子一片空白时，这个 Skill 会通过闲聊式提问帮你梳理一天。

**触发方式：**
- 输入 `/diary`
- 说"写日记"、"今天过得怎么样"

**工作流程：**
1. 用轻松的语气逐一提问（今天过得怎么样？有什么开心的事？学到什么？想对自己说什么？）
2. 根据回答追问细节，不机械、不强迫
3. 最后整理成一篇结构化的 Markdown 日记
4. 保存到 `~/Documents/日记/YYYY-MM-DD.md`

**核心设计：**
- 像朋友聊天，不是问卷调查
- 用户回答少就追问，说得多就共情
- 不评价内容好坏，不强迫回答

### 2. 经历库 — 个人经历与灵感数据库

你的人生记录仪。记录真实经历、灵感碎片、情绪片段、人际观察——不粉饰、不编造、不熬鸡汤。

**存储结构：**
```
~/Documents/经历与灵感/
├── 学业/     # 学习、课程、实验、考试
├── 人际/     # 关系、对话、冲突、温暖
├── 创意/     # 灵感、想法、写作片段
├── 情绪/     # 内心波动、反思
└── 日常/     # 生活琐事、观察
```

**支持的操作：**
| 指令 | 示例 | 作用 |
|------|------|------|
| 记录 | "记录一下，今天..." | 创建新记录，自动分类命名 |
| 查看 | "查看 学业" / "最近7天" | 按分类或时间浏览 |
| 搜索 | "搜 光学" | 全文关键词检索 |
| 回顾 | "回顾 2025" / "回顾 情绪" | 带温度的阶段性回顾 |
| 读取 | "读 2026-04-22-xxx" | 展示单条完整内容 |

**文件命名规范：**
```
YYYY-MM-DD-[一句话描述].md
```

**核心纪律：**
- 不改用户原话，保留粗糙感
- 不编造细节，模糊就照录
- 不主动追问，记录完就停

## 安装方法

### 方式一：复制到 Skills 目录

```bash
# Claude Code 的 skills 目录
cp -r diary 经历库 ~/.claude/skills/
```

重启 Claude Code 后即可通过 `/diary` 或 `/经历库` 调用。

### 方式二：项目内使用（推荐）

将本仓库中的 Skill 目录复制到你的项目 `.claude/skills/` 下，仅在该项目生效。
