# 提示词工程技术分类

## 基础技术

| 技术 | 描述 | 适用场景 |
|------|------|---------|
| **Zero-shot** | 无示例，直接给指令 | 简单任务、快速原型 |
| **Few-shot** | 提供少量输入-输出示例 | 格式敏感任务、分类任务 |
| **Chain-of-Thought (CoT)** | 要求模型展示推理过程 | 复杂推理、数学、逻辑 |
| **Self-Consistency** | 多次采样取最一致答案 | 需要高可靠性的推理 |
| **Role Prompting** | 指定模型扮演特定角色 | 专业领域、风格控制 |

## 结构化技术

| 技术 | 描述 | 适用场景 |
|------|------|---------|
| **Delimiters** | 用分隔符区分指令/上下文/约束 | 多段输入、复杂任务 |
| **Output Formatting** | 显式指定输出格式（JSON/Markdown） | API 集成、结构化输出 |
| **Task Decomposition** | 将复杂任务拆分为子任务 | 多步骤工作流 |
| **Constraint Injection** | 显式列出约束条件 | 需要精确控制输出 |

## 优化技术

| 技术 | 描述 | 适用场景 |
|------|------|---------|
| **Automatic Prompt Optimization** | 算法自动搜索最优提示词 | 大规模部署 |
| **Prompt Chaining** | 多个提示词串联执行 | 复杂工作流 |
| **Meta-Prompting** | 用 LLM 生成/优化提示词 | 提示词工程自动化 |
